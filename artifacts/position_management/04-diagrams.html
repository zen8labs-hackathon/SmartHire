D-02-6 · Sơ đồ tuần tự (đề xuất cho dev)

sequenceDiagram
  actor U as HR / Chapter Head
  participant UI as SmartHire UI
  participant API as Position API
  participant S as File storage
  participant Q as Job queue
  participant X as Trích xuất / OCR
  participant AI as AI Model
  participant N as Thông báo SSE / push
  U->>UI: Upload và extract
  UI->>API: Tạo vị trí (file, chapter, hire type, headcount)
  API->>S: Lưu file JD
  API-->>UI: Draft #id

  X-->>Q: Văn bản
  Q->>AI: Điền trường và tiêu chí

  Q->>API: Cập nhật Draft
  API->>N: Sự kiện JD processed
  N-->>U: Thông báo và toast
